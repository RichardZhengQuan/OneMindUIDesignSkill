Style system

Define the shared visual language that turns standards into consistent elements, components, and pages.

Style principles

Keep every surface calm, precise, trustworthy, and fast to scan.

Baseline
Restrained neutrals, clear hierarchy, generous breathing room, subtle depth, and purposeful accent color.

Color

Use semantic roles so light and dark surfaces preserve the same meaning.

Usage
Neutrals carry identity; blue supports links, focus, selection, and information without becoming every primary action.

Typography

Use the system sans stack with a compact, readable hierarchy.

Usage
One clear page title, logical headings, readable line lengths, and tabular numerals for changing values.

Spacing & layout

Build rhythm from shared spacing and grid tokens rather than page-specific offsets.

Usage
Align rails, titles, content, and actions to a stable grid while allowing localized text to wrap without clipping.

Shape & depth

Use precise corners and restrained elevation to explain containment and overlap.

Usage
Reserve stronger shadows and higher layers for temporary surfaces such as dialogs, menus, and feedback.

Motion

Use short, quiet transitions to clarify state changes without delaying work.

Accessibility
Respect reduced motion and never rely on movement alone to communicate meaning.
